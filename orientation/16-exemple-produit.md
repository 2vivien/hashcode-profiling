# Exemple produit — du profil à l'exploration

## Situation

Un élève :

- progresse en sciences ;
- progresse en mathématiques ;
- aime comprendre comment les choses fonctionnent ;
- aime résoudre des problèmes ;
- aime aider les autres ;
- est curieux ;
- connaît encore peu les domaines professionnels.

## Profil

### Investigateur–Social

Signaux :

- Investigative : forte ;
- Social : forte ;
- curiosité : forte ;
- résolution de problèmes : forte ;
- sciences : progression positive ;
- mathématiques : niveau intermédiaire, tendance positive ;
- aide aux autres : forte.

Incertitudes :

- peu d'expérience technique ;
- préférence théorie/pratique inconnue ;
- connaissance limitée des formations.

## Directions proposées

### Sciences et santé

Pourquoi ?

- intérêt scientifique ;
- résolution de problèmes ;
- composante sociale.

À explorer :

- expérimentation ;
- sciences de la santé ;
- activités de résolution.

### Ingénierie et technologies

Pourquoi ?

- intérêt pour les systèmes ;
- raisonnement ;
- progression quantitative.

À renforcer :

- mathématiques ;
- physique ;
- projets techniques.

### Informatique et données

Pourquoi ?

- raisonnement ;
- curiosité ;
- résolution de problèmes.

Incertitude :

- l'élève n'a pas encore suffisamment programmé pour savoir si cette activité lui plaît réellement.

Expérience :

- mini-projet Python ;
- analyse d'un petit jeu de données.

### Recherche

Pourquoi ?

- curiosité ;
- goût pour comprendre ;
- persévérance.

### Enseignement scientifique

Pourquoi ?

- intérêt scientifique ;
- aide aux autres ;
- composante sociale.

## Ce que le moteur ne dit pas

Il ne dit pas :

    « tu dois devenir médecin »

ou :

    « tu es fait pour l'informatique »

Il dit :

    « voici plusieurs directions cohérentes avec les informations
    actuellement disponibles ; voici pourquoi elles apparaissent,
    ce qui reste incertain et ce que tu peux explorer. »

## Après une expérience

L'élève réalise un mini-projet Python et répond :

    « J'ai aimé analyser les données, mais je n'ai pas aimé coder longtemps. »

Mise à jour :

- analyse de données : intérêt en hausse ;
- programmation longue : intérêt en baisse ;
- confiance : en hausse.

Le moteur ne supprime pas automatiquement l'informatique.

Il peut faire émerger :

- data ;
- recherche ;
- sciences ;
- ingénierie appliquée.

## Deuxième expérience

L'élève réalise un projet de robotique :

    « J'ai adoré construire et tester. »

Nouvelles observations :

- intérêt pratique : en hausse ;
- intérêt technique : en hausse ;
- persistance : observée.

Le profil change.

## Principe central

Le moteur n'a pas découvert un métier caché.

Il a aidé l'élève à produire de nouvelles informations sur lui-même.

    question
    → hypothèse
    → expérience
    → découverte
    → mise à jour
    → nouvelle hypothèse

C'est le cœur du moteur Otheloo.
