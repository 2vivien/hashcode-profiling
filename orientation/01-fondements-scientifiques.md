# Fondements scientifiques

## RIASEC — Holland

Six familles d'intérêts :

- Realistic ;
- Investigative ;
- Artistic ;
- Social ;
- Enterprising ;
- Conventional.

RIASEC peut constituer une représentation des intérêts, mais ne doit pas devenir une table « profil = métier ».

Utilisation :

    intérêts → environnements compatibles → directions à explorer

## Social Cognitive Career Theory

La SCCT relie notamment :

- expériences d'apprentissage ;
- auto-efficacité ;
- attentes de résultats ;
- intérêts ;
- objectifs ;
- contexte.

Architecture utile :

    expérience → auto-efficacité → intérêt → intention → exploration

Le contexte doit rester présent : possibilités de formation, ressources, contraintes et environnement.

## Bandura — auto-efficacité

Séparer :

- capacité observée ;
- confiance perçue ;
- volonté d'apprendre ;
- expérience antérieure.

Exemple :

    compétence actuelle : moyenne
    auto-efficacité : faible
    intérêt : élevé
    progression : forte

Ce profil n'est pas équivalent à :

    compétence : faible
    auto-efficacité : faible
    intérêt : faible
    progression : faible

## Savickas — adaptabilité de carrière

Quatre dimensions sont particulièrement utiles :

- concern ;
- control ;
- curiosity ;
- confidence.

Otheloo peut donc suivre la capacité à :

- se projeter ;
- prendre progressivement la main ;
- explorer ;
- gagner en confiance.

## Valeurs

Dimensions possibles :

- autonomie ;
- sécurité ;
- stabilité ;
- créativité ;
- contribution sociale ;
- rémunération ;
- apprentissage ;
- leadership ;
- variété ;
- travail collectif ;
- équilibre de vie.

Une direction peut être techniquement compatible mais peu compatible avec les valeurs.

## Personnalité

Big Five ou HEXACO peuvent être complémentaires.

Règle :

> un trait est un signal descriptif, pas une frontière professionnelle.

## Trajectoire scolaire

La dynamique compte autant que l'état actuel.

Exemple :

    8 → 10 → 12 → 14

diffère d'une trajectoire :

    16 → 15 → 14 → 12

Indicateurs :

- niveau ;
- tendance ;
- variance ;
- régularité ;
- vélocité ;
- contexte ;
- persistance.

Régression de base :

    y_t = β0 + β1 t + ε_t

β1 mesure une tendance, pas une capacité intrinsèque.

## Profil formel

On peut représenter :

    P_t = (I, A, S, K, V, E, SE, CA, T, X, C)

avec :

- I : intérêts ;
- A : aptitudes ;
- S : compétences ;
- K : connaissances ;
- V : valeurs ;
- E : environnement ;
- SE : auto-efficacité ;
- CA : adaptabilité ;
- T : trajectoire ;
- X : expériences ;
- C : contexte et contraintes.

Chaque dimension peut être absente ou incertaine.

## Règle scientifique

Aucun modèle isolé n'est la vérité du profil.

Le moteur doit croiser plusieurs familles de signaux et conserver leur provenance, leur date et leur confiance.
