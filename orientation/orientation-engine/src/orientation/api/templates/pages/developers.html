Couches du moteur

Ce qui décide vraiment du score, et ce qui est branché mais inactif. Une couche sans modèle entraîné le dit — elle ne produit pas un score qui aurait l'air trained.

Contexte RAG

Index documentaire construit sur la connaissance réellement chargée. Sert à répondre en langage naturel et à sourcer les explications.

Connexion

Paramètres non sensibles. Le mot de passe vit uniquement dans .env côté serveur.

Le moteur est un service séparé. Otheloo (et tout autre consommateur) l'appelle par HTTP — il n'y a aucune dépendance de code croisée.
