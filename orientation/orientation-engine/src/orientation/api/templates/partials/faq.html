Questions fréquentes

Ce qu'on nous demande le plus.

Est-ce que le moteur choisit un métier ?

Non, jamais. Il propose plusieurs directions à explorer, avec leurs raisons et leurs incertitudes. La décision reste humaine.

Un score faible ferme-t-il une voie ?

Non. Une faible compatibilité actuelle n'est pas une impossibilité. Le moteur sépare compatibilité, accessibilité, incertitude et compétences à renforcer.

Où sont les données ?

Le service est indépendant. Il ne traite pas encore de dataset réel — la base de connaissance ESCO/O*NET n'est pas exhaustive et aucune banque psychométrique n'est calibrée. Nous l'affichons clairement plutôt que de le masquer.

Comment l'intégrer ?

Par API REST/JSON : aucun code n'est fusionné. Consommateurs comme Otheloo appellent les endpoints. Voir l'espace développeur.
