## Règle documentaire

Chaque composant du moteur doit avoir :

1. une définition ;
2. une source ;
3. un cas d'usage Otheloo ;
4. une limite ;
5. une stratégie de validation ;
6. un statut : prototype, expérimental ou production.

Les liens GitHub servent à étudier les implémentations ; ils ne remplacent pas les preuves scientifiques.
