## Méthode

Les projets GitHub servent à étudier les implémentations de cosine similarity, skill matching, embeddings, graphes et ranking. Ils ne constituent pas des preuves de validité psychologique.

Pour chaque composant :
1. théorie ;
2. article original ;
3. méta-analyse ou revue ;
4. instrument ou référentiel officiel ;
5. implémentation ;
6. baseline ;
7. expérimentation ;
8. mesure ;
9. validation.
