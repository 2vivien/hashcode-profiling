# Roadmap V1 à V7

## V1 — Profil explicable

- intérêts ;
- valeurs ;
- auto-efficacité ;
- adaptabilité ;
- trajectoire ;
- expériences ;
- scoring simple.

Sortie : profil + premières directions.

## V2 — Directions

Ajouter :

- familles de domaines ;
- skill gaps ;
- explications ;
- diversification ;
- feedback.

Sortie :

    5 à 10 directions réellement différentes

## V3 — Knowledge graph

Ajouter :

- ESCO ;
- O*NET ;
- compétences ;
- formations ;
- professions ;
- relations ;
- contexte local.

## V4 — Exploration

Ajouter :

- activités ;
- mini-projets ;
- découverte ;
- feedback ;
- mise à jour longitudinale.

Cette phase correspond au rôle d'orientation décrit dans la feuille de route produit Otheloo.

## V5 — Learning-to-Rank

Quand suffisamment de données existent :

- ranking appris ;
- comparaison aux baselines ;
- calibration ;
- audit fairness.

## V6 — Bayesian + bandits

Tester :

- Bayesian updating ;
- Thompson Sampling ;
- LinUCB ;
- UCB.

Uniquement pour des explorations réversibles et à faible risque.

## V7 — modèles avancés

Si les données le justifient :

- embeddings ;
- graph embeddings ;
- GNN ;
- modèles multi-objectifs ;
- personnalisation avancée.

## Gate de passage

Chaque nouvelle version doit démontrer un gain sur :

    qualité
    calibration
    diversité
    explicabilité
    fairness
    expérience

Sinon la version précédente reste la référence.
